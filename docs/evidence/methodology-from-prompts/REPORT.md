# Methodologies drafted from the operator's prompts (2026-11-11)

Nothing was applied to the EU or the local store. Drafts: `drafts/NN_<slug>.json` (the real methodology_create input in `payload`, plus `source_quotes`, `overlap_check`, `memory_links`). Apply: `tools/methodology-from-prompts/apply.mjs` (dry run by default; `--apply` only when the operator says; fails closed on an old crate, a same-name Create, or an ambiguous Update target).

## Method
- Read the operator's 104 substantive prompts in this session's transcript (pasted summaries and notifications skipped), the 25 memory files, AGENTS.md and the docs doctrine.
- Checked the 50 built-in methodologies (assets/methodologies) and the 98 EU methodologies (rules review, regen report, consolidations) for overlap first; where one already holds the topic the draft is an add-only `update` of it instead of a new methodology.
- 'Sound = all rules apply': each rule's condition is true whenever its methodology is gathered; no incident ids, no fixed caps, no confidence, `requires` left empty (no provider is needed, so nothing can name an unregistered one). Two rules that repeated another draft's rule or a built-in's rule were removed while drafting.
- Lint over every rule: no 4-5 digit literals, no confidence/number literals outside the one methodology about them, keywords of at most three words.
